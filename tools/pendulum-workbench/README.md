# 單擺沉浸式工作臺（本機原型）

2026-09-27。獨立工具頁，入口 `index.html`。不依賴外部字型、CDN、套件或登入。沒有修改現有課程頁、投影片、紙本、共用導覽與其他既有未提交修改。尚未發布。

## 使用

在「課程網站」啟動 `python3 -m http.server 8765 --bind 127.0.0.1`，開啟 `http://127.0.0.1:8765/tools/pendulum-workbench/`。

1. 場景預設填滿整個視窗；點「操作器材」打開面板，先寫下預測；保存後才可釋放擺錘。
2. 設定懸掛長度、角度與質量。可拖動擺錘設定角度、拖動尺的零點；有滑桿替代拖動，手機可放大讀尺。
3. 釋放後面板收起，浮動碼錶出現。手動開始／停止碼錶，填量得長度及實際數到的完整來回次數，保存量測。可同條件重複或重新架設。
4. 筆記保存各次條件、量測與觀察；排除數據需要理由，可重新納入。原始量測不刪除。
5. 分析電腦可選擺長／角度大小／質量對週期或週期平方，手動觸發直線擬合與殘差圖。混合控制條件有提醒。
6. 論證欄位由學生填寫。可匯出全部數據 CSV、完整 JSON 實驗檔（可匯入）、Markdown 探究紀錄。

資料儲存在 `sssh-pendulum-workbench-v1` localStorage。JSON 匯入取代前會顯示確認與下載原資料按鈕。不使用其他單元的儲存鍵。尚未接上教師收件或班級資料庫。

## 模型與驗證邊界

- RK4 固定步長 1/240 s，解 `θ″=−9.81/L × sin θ`，包括大角度效應。
- 理想繩、質點、無摩擦。擺錘圖像大小不代表物理半徑。尺比例 330 SVG 單位/m，每格 1 cm。
- 資料分析使用學生讀尺輸入的長度，設定長度另外保存供追溯。碼錶使用真實 elapsed time 並量化至 0.01 s，不另加隨機噪聲。
- 切換分頁、離開實驗桌、超過 0.5 s 的畫面中斷，都會中止未保存的計時。
- 模擬數據不能獨立驗證生成它的方程；未宣稱已重現真實器材的阻尼、形變或操作手感。
- 原型用來驗證完整探究流程，尚未擴充 Lv2/Lv3 模式，也沒有自動評分。

## 滿版介面（2026-09-27）

場景填滿視窗，器材面板可收起；筆記、分析及論證浮在原場景上。底部保留工作區切換，Esc 可回實驗桌或收起面板。右上「全螢幕」使用瀏覽器支援的 Fullscreen API；不支援時維持視窗滿版。模型說明、載入備份放在「說明」。

已追加驗證：1440×900、768×900、390×844、900×480 的場景尺寸等於視窗；桌面與手機的開面板、釋放、計時、保存、切換分析、Esc、說明與放大讀尺。
